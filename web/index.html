ATOM Lite
Web Flasher

アプリのインストールは不要です。ATOM LiteをUSBで接続し、 ChromeまたはEdgeからファームウェアを書き込めます。

Firmware v@FIRMWARE_VERSION@

B.B. Link for ATOM Lite

このインストールではフラッシュ全体を書き換えます。保存済みの無線機、 ペアリング情報、設定は消去されます。

Web Serialに対応したデスクトップ版ChromeまたはEdgeで開いてください。 iPhone／iPadのブラウザには対応していません。

Web Serialを利用するため、HTTPSで公開されたページから開いてください。

シリアルポートへのアクセスは、ブラウザの確認画面で選択した端末に限られます。

書き込み手順

  1. 1
    USBで接続データ通信対応ケーブルでATOM LiteをPCへ接続します。
  2. 2
    書き込みを開始上のボタンを押し、ATOM Liteのシリアルポートを選択します。
  3. 3
    完了まで待機USBケーブルを抜かず、完了表示後に端末を再起動します。

接続できない場合

Arduino IDEやシリアルモニターなど、ポートを使用しているアプリを閉じてから 再試行してください。充電専用USBケーブルでは書き込めません。
